## Workshop folders

Open any folder as a project, right where it is.

- **Open folder…** (`Ctrl+O`), or drop a folder on the workshop
- Turn cslol and Fantome mod folders into projects
- Add a whole folder of mods at once
- Get back to recent projects from the **New project** menu or `Ctrl+R`

## Game Data Declarations

- Organize your declarations into **modules**
- Create, duplicate and remove objects in game bins
- Browse a layer's `game_data.yaml` as an outline, or from the new **Declarations** sidebar view
- Turn declarations on or off per project

## Bin Editor

- Edit a bin's **Dependencies**: add, remove and reorder them

## Material Editor

- See which rows you changed, and put a value back with one click
