## Particle Editor

- **Hexshade** now draws particles with the game's shaders, including custom materials on mesh
  emitters
- `Alt+Up` and `Alt+Down` open the previous or next particle system in the folder. In the Objects
  grid or tree, rest on a system with the arrow keys to open it in the preview
- The next system opens with the same camera, so you can compare systems at one angle. The camera
  fits the system only when it is out of view
- The transport moved into the timeline's header, with a new **Restart** button and a **Loop**
  toggle (`L`). `End` pauses at the end of the effect
- Drag the ruler to scrub. `Shift` and a drag sets a loop range
- A particle system that fails to load shows the error and a **Retry** button
- The effect waits for its first textures and meshes, for up to four seconds, so a short effect
  plays from its first frame
- In a narrow layout, the preview stays in view while the sections scroll
- Objects tiles have a **Large preview** button

## Game Data Declarations

- **Rename** a module (`F2` or double-click), **Move up** or **Move down** (`Alt+Up`, `Alt+Down`),
  or **Remove module**, from the outline or the **Declarations** view
- Drag entries between modules, or use **Move to module** and **New module…**
- **Write new edits here** picks the module that edits in a game bin go to
- **Show in text** opens a module in `game_data.yaml`
- The outline is a compact list with counts of keys, objects and overrides
- A module can be empty

## Bin Editor

- Undo and redo work anywhere in the editor: `Ctrl+Z`, and `Ctrl+Shift+Z` or `Ctrl+Y`
- Move through the tree with the arrow keys, and press `Enter` or `F2` to edit a value
- A refused edit keeps the text you typed, and `Esc` discards it
- A tab whose save failed or was blocked shows the unsaved dot
- Undo keeps expanded rows open
- A name you type into a field shows as that name, not as a hash
- Paths under any folder, such as `mod/83f7e874bb9f/...`, link to their files

## Hexshade

- Draws materials that come from a linked bin
- Draws both passes of a two-pass material
- The map backdrop uses a project's modded map materials instead of the game's
- Draws materials with a **Depth Compare Func** of `0`, such as eye blink materials
- A material's parameter values take priority over the values of its shader pass

## Workshop

- **Collapse all** on every tree, as a header button or `Ctrl+Left`
- `Alt`, `Shift` or `Ctrl` and a click on a folder's arrow expands or collapses everything under it
- In a narrow pane, toolbar controls move into a **More** menu

## Library

- The health check after an import uses less CPU and shows progress in the same toast as the
  startup check, with a **Stop checking** button
- Health checks skip bins that are identical to the game's copy. A mod that resets every
  champion's skins now checks much faster

### Fixed

- Maps with an unused vertex buffer failing to open
- Some animations with compressed tracks failing to load
- Particle alpha cutoff and colour drawing in a different order than in the game
- **Back** doing nothing after opening a project that restores its tabs
- Lists losing their scroll position when switching tabs
- **Stop Test** buttons responding while the test was already stopping, and **Remove from list**
  being available during a test
