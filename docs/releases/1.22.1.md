## Built-in Mods

Two new map mods in **Settings > Built-in mods**. Both are off by default and only change what you
see.

- **Map skin**: keep the skin the game picks (**Game**), play on the normal map during events
  (**Classic**), or pick any map skin in your install (**Chosen**). Only the map's environment
  changes. Minions, turrets, music and the loading screen still follow the event
- **Map decorations**: set the **Hall of Legends**, **MSI winner effects** and **Esports banners**
  to **Hidden** or **Always**
- The first patch after turning one on takes a while. The overlay keeps its own copy of each map
  archive, which is several GB
- A listed map skin can still fail to load, so try a new one in the Practice Tool first

## Previews

- **Anti-aliasing** in the **View mode** menu smooths edges the way the game does. Pick
  **FXAA (in game)**, **SMAA** or **Off**
- Characters on a map are lit by the map's light grid, as in the game. This applies to skin
  previews with a **Map backdrop** and to characters in map previews, on maps that have a light grid
- **Hexshade** now draws structures, jungle camps and props, and skin submeshes that only set a
  texture
- With **Hexshade** on, characters on maps without a light grid follow the map's sun and the
  **Sun** popover

## Objects Browser

- Hover a tile to play its preview in place: particles loop, materials spin and skins turn. Press
  `Space` for the large preview
- Previews stay for the whole session, so returning to a folder or clearing a search shows them
  right away. They are also sharper on high-DPI screens
- Late-starting particles, and materials whose shader cannot be drawn, now get a preview. Objects
  with nothing to draw show **Nothing to preview** instead of failing
- Retry failed previews from the toolbar, or one tile with **Retry preview** in its right-click menu
- Redesigned tiles, and **Grid** and **Tree** keep the same selection

## Bin Editor

- Path fields suggest project and game files as you type, with files of the right kind first:
  textures for a texture field, meshes for a mesh field
- Class and field cards show docs from the LoL Meta Wiki, with **Notes** and **Examples**. Field
  cards link to their section of the wiki

## Particle Editor

- New **Primitive** group: pick the emitter's **Render Primitive** from a list with a description
  and a sketch of each shape, and edit all of its fields in place
- Adding, removing or reordering emitters keeps the playhead instead of restarting the effect
- Edits no longer make emitters flash untextured, and scrubbing after a colour or texture edit no
  longer replays from the start

## Diagnostics

- New **Shader Compilation Failure** verdict for games that stop after League fails to compile a
  shader. When the cause is a mod that defines a `CustomShaderDef` outside
  `data/shaders/shaders.bin`, it says so
- **Loading Screen Stall** names the range of loading steps that could have hung, with corrected
  step names

### Changed

- Previews use FXAA by default instead of the old multisampling. **Off** now means no smoothing at
  all
- Particle previews hide low-spec substitute and colourblind-only emitters, as the game does at Very
  High effects quality
- The large Objects preview opens with `Space` instead of on hover
- Restyled segmented controls

### Fixed

- Files a project adds or replaces showing as missing, or previewing the game's copy, in a game bin
  opened to declare edits
- Material inspector tables cutting off texture names in a narrow pane
- Surface box spawn shapes only spawning from four sides, and legacy spawn shapes with several emit
  rotations spawning in the wrong direction
- **Orient Along Direction** particles flipping when moving close to vertical
- Beam offsets not rotating with the system
- A particle showing a snapshot of the screen instead of its texture while a distortion emitter was
  on screen
- A distortion emitter with strength 0 drawing as a coloured sprite
- **Soft Particles** and **Depth Offset** in the **Top**, **Front** and **Side** views
- Missing erosion maps drawing as solid white
- A hidden trail or beam leaving its wireframe on screen
- **Reroll the seed** giving nearly the same result
