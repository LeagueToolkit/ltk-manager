### Changed

- The patcher is downloaded instead of shipped with the app, so an out-of-date copy no longer stops a session with `Unsupported Game Build`. A fresh install needs to reach the download service before its first patch
- The patcher no longer runs as administrator. If League is set to run as administrator, the start message offers **Fix**, which copies the commands that clear the setting and opens an administrator terminal for you to review and run them
- LTK Manager itself must not run as administrator to patch, and the setting that elevated the patcher is removed
- A skin with a `RoughnessMetallicAoTexture` previews with the game's PBR shader, and with its normal map where the mesh has tangents
- The wireframe overlay is greener and draws each edge once, and it fades on small or distant meshes
- Character outlines and every other viewport draw with smoother edges
- The skin preview shows one gizmo at a time, and a socket moves along its own orientation by default
- Settings tabs have a cleaner layout, and the RuneForge section shows a failed status read

### Added

- Object tabs have a menu bar. A skin gets **File**, **View**, **Animation**, **Skin**, **Physics** and **Spells** menus, and an animation graph adds a **Clip** menu
- **View > Character outline** turns a skin's outline on and off in the preview
- Socket gizmo: **W** moves, **E** turns and **X** switches between the socket's own axes and the scene's. **Ctrl** snaps a drag and **Esc** cancels it
- Link an author profile to your RuneForge account in **Settings > Workshop > Author profiles**

### Fixed

- Clips, tracks, events and bones that a mod adds show their names in the editor instead of hashes. Names come from your game data and from the `.skl` files in your project
- **Copy as declaration** writes those names too
- The clip filter finds a clip by its hash
- Maps that clone a material no longer crash the game while loading
- Socket drags: a key pressed during a drag no longer changes what the drag writes
- Colliders: a new collider file is named per skin, so skins sharing a skeleton no longer overwrite each other's file
- Preview switches for conditions and pose modifiers no longer point at the wrong item after a remove or an undo
- Material overrides that only set PBR maps keep the skin's material, and the Material pane opens the material a submesh actually draws with
- A clip whose `.anm` is missing is no longer offered as playable, and event visibility puts back only what the event changed
- Files added or changed in a layer from outside the app refresh the open skin preview
- A refused remove in the skin inspector now shows an error, and **Add effect** waits for the skeleton so an effect is not written without a bone
