### Added

- Preview a project with some of its layers. **Sandbox options > Layers** on a skin, VFX or map tab picks the layers that stack, and the preview updates in place when the choice changes
- A layer file's rows show the file on disk, with marks on the values it overrides
- **Background** on the skin and map viewports sets a color behind the model and the map. It is kept between sessions, and a reset brings the sky back. The ground turns off for a color meant for keying
- **Capture** saves the viewport as a PNG at its drawn size, without the orientation gizmo or joint names. Overlays that have their own switch, such as the armature or physics shapes, are in the capture while on
- Diagnostics: **LTK Manager not running as admin** names why the app runs as administrator, such as User Account Control off, a compatibility flag or an elevated program that started it, with the steps for that cause and a fix command where one applies
- Diagnostics: **League and Riot Client not running as admin** checks the running client and game processes

### Changed

- Open documents stay loaded when a group closes, a split opens, a tab moves or a group is maximized, so a viewport no longer reloads its model
- A layer change keeps the textures and materials it does not touch, so the viewport no longer reloads them
- A patcher start that could not download the patcher says what failed and what to do, such as a blocked connection, a build the download service refuses, or a version of LTK Manager that is out of date
- A locked group that loses its last tab keeps its size, focus and maximized state. Unlocking it closes it. A document opened without a target skips an empty locked group, and a drop or an explicit open still lands in one

### Fixed

- Clicking a layer in **Sandbox options > Layers** applies the choice
- A declared object created in a game chunk the hash tables name, such as `data/characters/chogath/skins/skin0.bin`, appears in the Objects browser and in the class counts
