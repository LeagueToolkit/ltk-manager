### Added

- **Character inking**, a new built-in mod in **Settings > Built-in mods**. It draws an ink outline around champions, as in League Classic. Pick the champions, the maps it draws on, a style, the color, thickness and opacity, and see the result in a preview before the patcher starts. **Lane minions** and **Structures** switches add the outline to minions, turrets, inhibitors and nexuses. The mod is off by default
- Install a whole collection from one link. An `ltk://install-list` link opens **Install Collection**, which lists every mod of the collection, marks the ones already installed at that version, and installs the checked mods into the active profile or into a new profile named after the list. **Stop** ends the run after the current mod, and **Retry failed** tries again only the mods that failed. The load order follows the order of the list
- **Keep sorted by** on a folder's menu, and on the library's own menu, keeps the folder in one sort: Name A-Z, Name Z-A, Champion, Newest first, Oldest first or Enabled first. New, renamed, updated and moved mods take their place by that sort, and the game loads them in that order. The folder card and header show the kept sort. Dragging a mod puts the folder back in manual order, with **Undo** on the toast
- When the library shows a sort other than **Load order**, a note says that the sort changes only the view. **Set as load order** makes the view's order the real load order, and **Keep this sort** makes every folder keep that sort
- Mod health checks and repairs `.modpkg` mods, as it does for Fantome mods. A repair keeps the package's readme, license, thumbnail and metadata
- A refused download from an install link says why and what to do: the link expired, the mod is no longer available, its files were removed, the site is limiting downloads (with the wait time), or there is no connection
- Navgrid guides in the map editor. The **Guides** menu tints the map by navgrid terrain or region tags, with an optional height cutoff, and each overlay has its own switch. **Pick cells** shows a cell's flags, region tags and overlays in the inspector, and **Snap to navgrid cell centers** places and drags to a cell center
- **Conformance** view mode in the map editor colors the ground by its height difference to the navgrid, and lists the areas where the ground leaves the navgrid or no ground covers a cell
- **Region boundaries** in the map editor draw in the viewport and appear as **Regions** in the outliner. Drag a vertex knob to move it, click an edge knob to add a vertex, and Alt-click a vertex to remove it. Grid snap applies, and Esc cancels a drag
- **Repeats** in the emitter's Emission group and in the timeline turns a repeating emission cycle on or off and sets its period and active time
- **Unset** on an option's row, shown on hover, empties the option so the game uses the default value. **Reset to default** on an option in a declared document does the same
- **Keys and gestures** sheet lists every shortcut and gesture of the app, with the keys of the current view first. Open it with `?` or `F1`

### Changed

- The **Projects** palette moves from `Ctrl+R` to `Ctrl+Shift+O`, because `Ctrl+R` reloads the app
- `Ctrl+1` to `Ctrl+3` in the explorer switch its view and no longer also change the page
- **Settings > Hotkeys** refuses a global hotkey that an in-app shortcut already uses
- The skin, VFX and material viewports show their controls on a bar along the top edge, as the map viewport does. **Frame** is on every bar. The bar wraps to a second line in a narrow pane
- The library remembers the chosen sort after a restart
- In the map editor, the inspector groups mesh fields in a label column, and position, rotation and scale each have a button for their tool. Visibility layers show the names of the map's flags
- In the map editor, a dragged mesh moves live in the viewport

### Fixed

- `Ctrl+S` on a Workshop project's details saves once, not twice
- In the map editor, dragging the gizmo no longer locks the camera, and undo after a drag shows the restored position
- In the map editor, blended surfaces draw in the correct order, and the selection wireframe no longer shows through other geometry
- The skin preview backdrop shows a map skin's grass tint
- A link to an object that a game data module creates opens that object

### Known Issues

- Character inking is not yet tested in a full game. If the game crashes with inking on, turn inking off before you look for another cause, because the crash report does not name built-in mods as a suspect
- Character inking on **All** champions adds about 16 GB to the overlay, and the first patcher start after you turn it on is slow. **Base skins** on every champion uses the same archives, so the two share most of that space
- Mod health does not yet read game data declarations. A `.modpkg` mod that holds only declarations always shows as healthy
