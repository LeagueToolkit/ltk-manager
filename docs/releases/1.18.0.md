## Anonymous diagnostics

The manager will now report instrumentation and diagnostics by default to make shipping bug fixes faster and easier.

- You can opt-out if you don't want to participate
- Anonymous by design, your ID is freshly minted every day and data is sanitized
- <https://wiki.leaguetoolkit.dev/manager/privacy>

## Experimental Object Class Views

- Added support for showing predefined meta classes in a special layout

## Game explorer cards/details list

- You can now view files as **Grid, details or tree**
- Added current path as breadcrumbs
- Explorer directories are now properly mapped to the browser's history stack
- Integrated sorting, filtering and search

## Editor tabs

- **Tab Pinning** allows you to pin editor tabs that you need to stay open
- **Group Locking** makes it possible to lock tab groups

## Performance

- Faster library rendering
- Better patcher polling
