## Bin viewer

Added an **experimental** block-based `.bin` viewer into the project editor.

- **Fully meta typed**: integration with the [Meta Wiki](https://meta-wiki.leaguetoolkit.dev/)
- **Scoped Object Tab**: open a single object as a tab in a block view
- **Link Resolution**: object link properties are automagically resolved
- **Texture swatches** rendered for texture `file` properties

## Objects browser and search

Global Search through the game's data system.

- **`$` in the command palette** searches objects, with a `class:` filter and completions

## League diagnostics

- **Archive Mount Failures** now get properly reported and offered a solution for
- **League Install Mismatch Prevention**: the manager will warn you if your seleced install path differs from the running instance during patching
- **Dismiss all** incidents
- Better names for League's loading steps

## Library

- **Select mods by gesture**: `Ctrl + Click` picks, `Shift + Click` ranges, `Ctrl+A` picks all
  visible.
- Added checkboxes to hovered cards
- Moved the diagnostic warning badge into the card corner

## Workshop

- Unified project card menu
- Better project renaming UX

## Settings

- **Open on** can now be set to `Workshop`
- The settings gear is back in the title bar

### Fixed

- Normalize displayed file paths

### ⚠️ Known issues

- **The bin viewer does not edit.** Leaf editing, saving and undo are the next track
- **Find references does not follow links.** An object query answers with its declarations,
  not with what points at it
- Some mods still report as healthy and break the game
